## 📖 حول البرنامج

**ASM Download Manager (ADM)** هو برنامج إدارة تنزيلات متكامل تم تصميمه ليقدم أعلى سرعة تحميل ممكنة مع استقرار تام وخفة فائقة في استهلاك موارد الجهاز.

يتميز البرنامج بواجهة عصرية تدعم 9 ثيمات مختلفة، ونظام متقدم لتحميل ملفات التورنت مع إمكانية متابعة تقدم كل ملف على حدة، والتقاط الفيديوهات تلقائياً من المواقع، إضافة لتكامل سلس مع جميع المتصفحات الحديثة.

## ✨ المميزات الرئيسية

* 🚀 **أقصى سرعة تحميل**: تقسيم الملف إلى اتصالات متعددة متزامنة لتحقيق أعلى سرعة يوفرها اتصالك بالإنترنت.
* 🧲 **دعم شامل للتورنت**: إمكانية تحميل ملفات التورنت وروابط Magnet، مع نافذة تفاعلية تتيح متابعة شريط تقدم ونسبة كل ملف على حدة (مثل uTorrent).
* 🎬 **التقاط الوسائط والفيديوهات**: كشف تلقائي للوسائط والفيديوهات بأعلى جودة مع إمكانية تنزيل الصوت فقط أو الفيديو مدمجاً بأعلى دقة.
* 🌐 **إضافة متصفح ذكية**: إضافة مدمجة لمتصفحات Chrome و Edge و Brave و Firefox للتحكم التلقائي والتقاط التحميلات بنقرة واحدة.
* 📋 **أداة زحف الروابط (Site Grabber)**: فحص صفحات ومواقع الويب وتنزيل محتوياتها بالكامل مع خيارات متقدمة للتصفية والتحديد.
* 🌙 **دعم حقيقي للوضع المظلم (Dark Mode)**: تصميم متكامل ومتناسق يريح العين ويمنع أي وميض للشاشة.
* 🔄 **تحديثات تلقائية**: ميزة فحص وتنزيل التحديثات تلقائياً عبر البرنامج بدون الحاجة لإعادة التثبيت اليدوي.
* 🌍 **واجهة متعددة اللغات**: دعم كامل للغة العربية (RTL) بالإضافة إلى 7 لغات عالمية أخرى.
